# Vue-router进入一个页面都经历哪些生命周期


在使用 Vue Router 导航到一个页面时，整个过程会涉及 **Vue Router 的导航守卫** 和 **组件自身的生命周期钩子** 两部分。以下是完整的流程和涉及的关键阶段：


### 一、导航守卫（路由层面的生命周期）
导航守卫是 Vue Router 提供的钩子函数，用于控制导航的流程（如权限验证、页面跳转等），执行顺序如下：

1. **全局前置守卫 `beforeEach`**  
   导航开始时触发，是整个导航流程的第一个钩子。可用于全局权限判断（如登录验证），决定是否允许导航继续。

2. **路由独享守卫 `beforeEnter`**  
   仅在当前路由配置中定义的守卫，针对特定路由生效，在全局前置守卫之后执行。

3. **组件内守卫 `beforeRouteEnter`**  
   即将进入的目标组件内的守卫（此时组件实例还未创建，`this` 不可用）。可通过 `next(vm => { ... })` 访问组件实例。

4. **全局解析守卫 `beforeResolve`**  
   在所有组件内守卫和异步路由组件解析完成后触发，确认导航即将被确认。

5. **导航确认**  
   此时路由正式更新（`$route` 变化）。

6. **全局后置钩子 `afterEach`**  
   导航完成后触发，不影响导航结果，常用于页面标题修改、滚动条重置等。


### 二、组件自身的生命周期（组件层面）
导航确认后，会触发新旧组件的生命周期钩子（旧组件卸载，新组件创建）：

#### 1. 离开当前页面（旧组件）
- `beforeRouteLeave`（组件内守卫，离开当前组件前触发，可用于确认是否离开，如未保存的表单）
- `beforeDestroy`（组件销毁前）
- `destroyed`（组件销毁完成）


#### 2. 进入新页面（新组件）
- `beforeCreate`（组件实例初始化前）
- `created`（组件实例创建完成，可访问数据和方法，但未挂载 DOM）
- `beforeMount`（组件挂载前）
- `mounted`（组件挂载完成，DOM 已生成，可操作 DOM）


### 完整流程总结
1. 触发导航（如点击 `<router-link>` 或调用 `$router.push`）  
2. 执行全局前置守卫 `beforeEach`  
3. 执行目标路由的 `beforeEnter`（路由独享守卫）  
4. 解析异步路由组件（若有）  
5. 执行目标组件的 `beforeRouteEnter`（组件内守卫）  
6. 执行全局解析守卫 `beforeResolve`  
7. 确认导航，更新 `$route`  
8. 执行全局后置钩子 `afterEach`  
9. 卸载旧组件：触发旧组件的 `beforeRouteLeave` → `beforeDestroy` → `destroyed`  
10. 挂载新组件：触发新组件的 `beforeCreate` → `created` → `beforeMount` → `mounted`  


### 特殊场景：路由参数变化（如 `/user/1` → `/user/2`）
此时不会卸载/创建组件，而是触发：  
- 组件内守卫 `beforeRouteUpdate`（可处理参数变化逻辑）  
- 组件的 `updated` 生命周期（数据更新后触发）


通过以上流程，Vue Router 实现了路由导航与组件生命周期的协同，确保页面切换时的逻辑（如数据加载、权限控制）按预期执行。
